# 산업연관분석 플랫폼

GitHub Pages에서 실행할 수 있는 산업연관표 분석 웹앱 프로토타입입니다.

## 포함 기능
- Excel(.xlsx, .xls) 파일 업로드 및 시트 선택
- 중간거래행렬 Z와 총산출액 x를 이용한 투입계수행렬 A 계산
- 레온티에프 역행렬 `L = (I - A)^-1` 계산
- 산업별 생산유발계수, 영향력계수, 감응도계수
- 최종수요 증가액을 입력하는 생산유발효과 시뮬레이터
- 산업별 순위 및 Chart.js 시각화
- 예시 데이터 다운로드

## GitHub 배포 방법
1. GitHub에서 새 **Public repository**를 만듭니다.
2. 이 폴더 안의 파일을 압축 해제한 뒤 저장소 최상위(root)에 모두 업로드합니다.
3. `Commit changes`를 누릅니다.
4. 저장소의 **Settings → Pages**로 이동합니다.
5. **Deploy from a branch**를 선택합니다.
6. Branch는 `main`, Folder는 `/(root)`로 설정하고 Save를 누릅니다.
7. Actions 탭에서 배포가 완료되면 `https://사용자이름.github.io/저장소이름/`으로 접속합니다.

## Excel 입력 구조
웹앱은 다음 형태의 데이터를 기본으로 가정합니다.

- 산업명: 설정한 헤더 행의 첫 산업 열부터 오른쪽으로 연속 배치
- 중간거래행렬 Z: 설정한 첫 산업 데이터 행부터 아래로, 첫 산업 열부터 오른쪽으로 `산업 개수 × 산업 개수` 정사각형 배치
- 총산출액: 선택적으로 총산출액 열을 지정하고, 첫 산업 데이터 행부터 산업 개수만큼 아래로 배치
- 행은 공급 산업(i), 열은 구매 산업(j) 기준이어야 합니다.

예시 엑셀을 내려받아 입력 구조를 확인할 수 있습니다. 업로드한 실제 산업연관표의 행·열 배치는 발행기관의 양식에 따라 다를 수 있으므로, 분석 전에 반드시 확인하고 설정값을 조정해야 합니다.

## 계산식
- 투입계수: `a_ij = z_ij / x_j`
- 생산유발계수행렬: `L = (I - A)^-1`
- 산업별 생산유발계수: L의 열합계
- 영향력계수: L의 열합계 / L 전체 원소 평균이 아닌 **열합계의 산업 평균**
- 감응도계수: L의 행합계 / 열합계의 산업 평균
- 최종수요 변화에 따른 생산유발액: `ΔX = L × ΔY`

## 중요한 한계
이 프로토타입은 중간거래행렬 Z와 총산출액 x가 정확히 지정되었다는 전제에서 계산합니다. 총산출액 열을 지정하지 않으면 Z의 열합을 대신 사용하므로 실제 총산출액과 다를 수 있습니다. 정식 산업연관표의 수입유발계수, 부가가치유발계수, 취업유발계수는 각각에 필요한 수입·부가가치·고용 관련 계수 또는 원자료를 추가로 연결해야 합니다. 이 버전은 해당 지표를 임의로 만들어 내지 않습니다.

이 프로젝트는 학습·과제용 프로토타입이며, 공식 통계 분석이나 정책 판단에 사용하기 전 원자료와 계산 결과를 검증해야 합니다.
