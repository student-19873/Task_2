05 / METHODOLOGY

분석 방법 및 유의사항

투입계수행렬

aᵢⱼ = zᵢⱼ / xⱼ

산업 j의 총산출액 중 산업 i의 투입이 차지하는 비율입니다.

생산유발계수행렬

B = (I − A)⁻¹

레온티에프 역행렬로, 최종수요 한 단위 변화에 따른 산업별 생산유발효과를 나타냅니다.

영향력계수

열합계 / 전체 평균

해당 산업의 최종수요 증가가 다른 산업의 생산을 얼마나 유발하는지 나타냅니다.

감응도계수

행합계 / 전체 평균

모든 산업의 최종수요 변화에 해당 산업이 얼마나 영향을 받는지 나타냅니다.

중요한 데이터 유의사항

이 웹앱은 사용자가 지정한 정사각형 중간거래행렬 Z와 총산출액 x를 바탕으로 계산합니다. 총산출액 열을 지정하지 않으면 Z의 열합을 대체값으로 사용하므로 정식 산업연관표의 총산출액과 다를 수 있습니다. 수입유발계수·부가가치유발계수·취업유발계수는 해당 계수행 또는 원자료가 추가로 필요하므로 이 기본 버전에서는 자동 산출하지 않습니다. 실제 과제 제출 전에는 데이터의 분류·단위·행렬 방향을 반드시 확인하세요.
